# Serenity Reforged

Serenity Reforged or just Serenity is my first Minecraft mod! It adds a fully custom lapidary system to minecraft. This crafting includes cauldron brewing, altar offerings and a custom lapidary grindstone block. 


## How this was made
This project was made with the **Fabric modding engine using Java**. For learning purposes, I try not to use any libraries at all. 


## How to run the project:

### For Modloaders (Curseforge, Modrinth, Prism, etc):

Make a new instance of Minecraft on fabric version 1.21.1. Then, import the
['.jar' file from the GitHub page](https://github.com/justanothernormalusername/Serenity-Reforged/releases).
Then, add the dependency of the mod [FabricAPI 1.21.1](https://modrinth.com/mod/fabric-api/version/0.116.17+1.21.1)

### For Non-Modloaders:

1. Download and run the [fabric installer](https://modrinth.com/mod/fabric-api), choose version 1.21.1
2. Press "Windows + R" or simply open "run" and type in the path `%appdata%\.minecraft`.
3. Add a new folder called `mods`
4. Within this folder, add the latest version of [FabricAPI 1.21.1](https://modrinth.com/mod/fabric-api/version/0.116.17+1.21.1) and the mod file from the GitHub.
5. Run minecraft through your launcher and enjoy!

**If you are using Linux the .minecraft directory is stored in ~/.minecraft**

**For Mac, .minecraft is at ~/Library/Application Support/minecraft**
